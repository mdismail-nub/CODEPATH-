## 2025-05-22 - "Copy Code" Micro-UX Improvement
**Learning:** Adding a "Copy Code" functionality to static code examples significantly improves developer UX by reducing manual selection friction. Combining this with a visual success indicator (icon swap using `AnimatePresence`) and accessible labeling (`aria-label`) creates a delightful and inclusive experience.
**Action:** Always look for static content that users might want to reuse (like code, commands, or keys) and provide a one-click copy affordance with clear visual feedback.
