## 2025-05-14 - Functional feedback for code examples

**Learning:** Static icons that resemble interactive controls (like a 'Play' icon in a code header) create "false affordances" that frustrate users. Replacing these with functional tools like a 'Copy Code' button with transient visual feedback ('Check' icon) provides immediate utility and delight.

**Action:** Always audit static decorative icons in headers or toolbars to ensure they don't mislead users into thinking they are interactive. If an icon looks like a button, it should be a button.
