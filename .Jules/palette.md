## 2025-05-15 - Replacing False Affordances
**Learning:** Static icons that resemble interactive controls (like a 'Play' icon in a code header) create false expectations for users. Replacing them with functional counterparts (like a 'Copy Code' button) improves both utility and user satisfaction.
**Action:** Always audit static decorative icons in high-interaction areas to ensure they don't mislead users into thinking they are clickable.
