## 2026-05-20 - [Aria Label and Tactile Feedback Pattern]
**Learning:** Icon-only buttons (like the problem solved toggle) need dynamic `aria-label` attributes to communicate state changes to screen readers. Adding `active:scale-95` provides universal tactile feedback for clicks.
**Action:** Always include `aria-label` for icon buttons and use `active:scale-95` for consistent interaction feedback across the app.
