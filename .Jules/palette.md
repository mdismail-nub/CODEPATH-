## 2025-05-15 - Enhancing Code Example Utility
**Learning:** Static icons in code headers (like a 'Play' icon) create false affordances that frustrate users. Replacing them with functional tools like 'Copy Code' aligns the UI with user expectations. Dual feedback (aria-label + icon swap) is essential for accessible clipboard operations.
**Action:** Always audit static decorative icons in headers to see if they can be converted into useful micro-actions, and ensure clipboard operations provide both visual and screen-reader feedback.
