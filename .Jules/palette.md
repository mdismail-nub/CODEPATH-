## 2025-05-15 - Improving Accessibility and Delighting Users with Code Copying

**Learning:** Users on educational platforms frequently need to copy code examples. Providing a functional "Copy Code" button instead of a decorative icon significantly improves the learning experience. Additionally, accessibility attributes like `aria-expanded` for toggles and `aria-label` for icon-only buttons are essential for inclusive design.

**Action:** Always look for decorative icons that can be turned into functional utilities. Ensure all interactive elements have proper ARIA attributes and provide tactile feedback (like `active:scale-95`) to make the UI feel more responsive.
