## 2025-05-15 - Micro-UX Tactile Feedback Pattern
**Learning:** Standardizing tactile feedback using `active:scale-95` across all interactive elements (buttons, logos, toggles) creates a cohesive, high-quality "physical" feel for the application.
**Action:** Always apply `active:scale-95` to new interactive components to maintain consistency with the Palette design system.

## 2025-05-15 - Accessible Toggle States
**Learning:** For toggleable UI elements like hints, combining `aria-label` with `aria-expanded` is essential to provide screen reader users with the same context as visual users.
**Action:** Ensure all future toggle components implement the `aria-expanded` attribute synchronized with their open/closed state.
